## Lynxx 2.1.0

Bản phát hành đầu tiên của Lynxx: app tải, đọc và xuất **truyện tranh, truyện chữ và sách**. Phần tải booru thừa hưởng từ Lustra đã được gỡ hẳn (trang tìm kiếm tag, extension booru, danh sách tag, lọc giới tính, model server, trình tạo extension AI).

- **Extension định dạng vBook** (cùng gói `plugin.json` + `src/*.js` mà app vBook dùng): cài từ thư mục, file `plugin.zip`, link hoặc kho extension (`…/plugin.json`); duyệt trang chủ, thể loại, tìm kiếm, dán link truyện. Script chạy trong sandbox Chromium riêng, chỉ ra mạng qua cầu nối của Lynxx: chặn địa chỉ nội bộ, giãn nhịp theo host, tôn trọng `Retry-After`. Extension mã hoá (`metadata.encrypt`) và các loại tts / translate / audio / video chưa được hỗ trợ.
- **Tải truyện**: mỗi truyện là một lượt tải; chương đã có không tải lại, "Cập nhật chương mới" chỉ tải chương mới. Ảnh tải vào thư mục tạm (`.part`, tải tiếp bằng `Range`, kiểm tra đúng là ảnh, huỷ được) rồi mới ghi vào thư viện kèm SHA-256. Tiến độ ở trang **Tải xuống**, có thông báo hệ thống khi xong.
- **Thư viện**: bìa, tác giả, giới thiệu, nguồn, số chương, chương đang đọc; tải chương chọn, cập nhật, xoá.
- **Đọc truyện**: truyện tranh cuộn dọc / trượt ngang / từng trang, trái → phải hoặc phải → trái (manga); truyện chữ chỉnh cỡ chữ; PDF bằng trình xem của Chromium. Mục lục, chương trước / sau, phím ←/→, `[` `]`, F (toàn màn hình); vị trí đọc được lưu theo chương.
- **Xuất**: EPUB 2, EPUB 3, KEPUB (Kobo), CBZ, PDF. Tuỳ chọn phạm vi, trang giới thiệu (bìa, tác giả, thể loại, mô tả), mục lục có link tới từng chương, tên chương, cách xử lý chương chưa tải (tải trước, bỏ qua, giữ link ảnh như vBook) và tự cập nhật file đã xuất khi có chương mới. Cấu trúc EPUB giống file của vBook; file vBook có chương chỉ chứa link ảnh nhập vào được, tải bổ sung rồi xuất lại đầy đủ.
- **Nhập từ máy** khoảng 30 định dạng: epub, txt, mobi, prc, azw, azw3, fb2, fbz, umd, pdf, cbz, zip, html, htm, xhtml, md, markdown, chm, doc, dot, wps, docx, docm, dotx, dotm, odt, ott, fodt, rtf, hwp, hwpx, hwpml. Chuyển đổi không cần mạng; sách có DRM bị từ chối; file gốc được giữ.
- **Giao diện theo icon**: theme mặc định **Abyss** (nền xanh navy đậm, nhấn cyan như icon); Paper và OLED cũng nhấn cyan, Graphite giữ tông xám. Người đang dùng theme cam cũ được chuyển sang Abyss.
- Lõi Python chỉ dùng thư viện chuẩn: bản cài nhỏ hơn và không cần cài gói Python nào khi chạy từ mã nguồn.
- Cài đặt cũ: các mục của phần booru (truy vấn đã lưu, API key, khoá Claude, model giới tính…) bị bỏ khi mở bản này; theme, icon, hình nền, proxy được giữ.

Bản macOS chưa ký: lần đầu mở, bấm chuột phải vào Lynxx → Open. Bản Windows chưa ký: SmartScreen có thể hỏi, chọn "More info" → "Run anyway".
