## Lynxx 2.0.4

Bản sau [2.0.3](https://github.com/Leiz-Workspace/Lynxx/releases/tag/v2.0.3): bật catalog extension từ xa.

### Thay đổi
- **Catalog extension từ xa đã dùng được.**
  - App có khoá công khai của catalog chính thức (`b852144452eea5dc`). Ô "Catalog URL" ở trang Extension mặc định là catalog đó:
    `https://github.com/Leiz-Workspace/Lynxx/releases/download/catalog/index.json`
  - Bấm "Tải danh sách" để xem và cài extension.
  - App kiểm chữ ký Ed25519 của catalog trước khi đọc, và kiểm sha256 của từng gói trước khi cài. Bản cũ hơn 2.0.4 vẫn từ chối mọi catalog từ xa.
- Cài extension từ file zip và catalog có sẵn trong app vẫn như trước.

- bản chạy độc lập `lynxx-model-server-<hệ điều hành>-<kiến trúc>-cpu_v2.0.4` (Linux x64 / arm64, Windows x64, macOS arm64; Windows có thêm bản `directml`);
- hoặc image Docker CPU (amd64 / arm64), lệnh `docker pull` ở cuối trang.

### Lưu ý
- Bản Windows và macOS **chưa ký số**:
  - Windows SmartScreen có thể hỏi trước khi chạy: chọn "More info" → "Run anyway".
  - macOS: lần mở đầu tiên, chuột phải vào app → Open.
- `SHA256SUMS.txt` có mã băm của mọi file; `build-info.json` ghi commit và lượt build tạo ra chúng.
- Extension là code Python chạy trên máy bạn với quyền của bạn: chỉ cài từ catalog bạn tin cậy.
