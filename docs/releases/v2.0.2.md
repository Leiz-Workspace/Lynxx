## Lynxx 2.0.2

Bản sửa nhỏ sau [2.0.1](https://github.com/Leiz-Workspace/Lynxx/releases/tag/v2.0.1).

### Thay đổi
- **Phần cứng của model server ghi đúng hơn.** Khi server chỉ thấy card NVIDIA qua driver của hệ điều hành mà không có `nvidia-smi` (ví dụ image Docker CPU chạy không có `--gpus`), log của server và dòng "Phần cứng của server" trong app ghi card đó là "VRAM unknown (no nvidia-smi)" / "không đọc được VRAM", thay vì "shared memory" / "dùng chung RAM" như thể đó là GPU tích hợp. Tên card đọc theo cách này cũng ghi đúng hãng ("NVIDIA GPU …"). Kết luận của app không đổi: model sẽ chạy bằng CPU.
- README mới cho Lynxx (thay README cũ kế thừa), kèm ảnh chụp giao diện; cú pháp tag và tài liệu giao diện Tk cũ chuyển vào `docs/`.
- Test trên macOS (đường dẫn tạm, OpenSSL không có `pkeyutl -rawin`) và workflow phát hành được sửa; image Docker của model server giờ kéo được công khai.

### Tải về
| Hệ điều hành | File |
|---|---|
| Linux x64 | `lynxx-linux-x86_64_v2.0.2.AppImage` hoặc `lynxx-linux-amd64_v2.0.2.deb` |
| Linux arm64 | `lynxx-linux-arm64_v2.0.2.AppImage` hoặc `lynxx-linux-arm64_v2.0.2.deb` |

| macOS Apple Silicon | `lynxx-mac-arm64_v2.0.2.dmg` (hoặc `.zip`) |
| macOS Intel | `lynxx-mac-x64_v2.0.2.dmg` (hoặc `.zip`) |

**Model server** (chỉ cần cho chế độ "Tag + model"): bản chạy độc lập `lynxx-model-server-<hệ điều hành>-<kiến trúc>-cpu_v2.0.2` (Linux x64 / arm64, Windows x64, macOS arm64; Windows có thêm bản `directml`), hoặc image Docker CPU (amd64 / arm64), lệnh `docker pull` ở cuối trang. GPU NVIDIA: xem phần "Gender model server" trong README.

### Lưu ý
- Bản Windows và macOS **chưa ký số**: Windows SmartScreen có thể hỏi trước khi chạy ("More info" → "Run anyway"); macOS: chuột phải vào app → Open ở lần mở đầu.
- `SHA256SUMS.txt` có mã băm của mọi file; `build-info.json` ghi commit và lượt build tạo ra chúng.
- Catalog extension từ xa vẫn cần chữ ký của nhà phát triển và chưa có khoá ký, nên mọi catalog từ xa bị từ chối; catalog có sẵn trong app và cài từ file zip vẫn dùng được.
