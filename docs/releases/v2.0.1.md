## Lynxx 2.0.1

Bản phát hành đầu tiên của Lynxx: app desktop (Electron) cho bộ tải booru dựa trên extension, phát triển từ mã nguồn gốc của [trickerer01](https://github.com/trickerer01) (MIT).

### Tính năng chính
- **Tìm và tải theo tag**: tag loại trừ, wildcard, meta tag, nhóm OR và nhóm loại trừ, gộp / tách tag ngay trên ô nhập; autocomplete và duyệt tag A–Z offline; đếm kết quả; preview dạng lưới (ảnh, video, âm thanh) và tải các post đã chọn; hàng đợi tải chạy nền với tiến độ, tốc độ, thời gian còn lại.
- **Extension cho từng site**: Rule34, Danbooru có sẵn; cài thêm từ catalog, file zip hoặc catalog từ xa có chữ ký Ed25519. **Tạo extension cho site mới** từ một link (có AI Claude hoặc không), luôn ra bản nháp để xem lại, không bao giờ tự cài; danh sách tên miền bị chặn; `lynxx.sdk` cho người viết extension.
- **Lọc theo giới tính nhân vật**: theo tag (giữ / loại bỏ các nhãn), kèm danh sách chặn an toàn; chế độ **Tag + model** dùng model nhận diện ảnh (WD ViT Tagger v3) cho post thiếu tag, chạy ở model server riêng; có thể xem lại video / ảnh động trên nhiều khung sau khi tải.
- **Index các lần tải**: trang "Đã tải" tìm offline, bỏ qua file đã tải giữa các site, dọn index, nhập thư viện có sẵn, tải một truy vấn từ nhiều site.
- **Truy vấn đã lưu** tự tải lại định kỳ, chỉ lấy post mới.
- Proxy (http, https, socks5), header / cookie theo site, nhận diện trang bot challenge (dừng, không vượt), 4 theme và 4 icon.

**Model server** (chỉ cần khi dùng chế độ "Tag + model"; app không kèm model để nhẹ):
- Bản chạy độc lập, không cần Python: `lynxx-model-server-<hệ điều hành>-<kiến trúc>-cpu_v2.0.1` (Linux x64 / arm64, Windows x64, macOS arm64); Windows có thêm bản `directml` cho GPU bất kỳ (chưa được thử trên máy thật). Lần chạy đầu tự tải model (~380 MB). Trong thư mục có script cho chạy nền khi đăng nhập.
- Image Docker (CPU, amd64 / arm64): lệnh `docker pull` ở cuối trang này. GPU NVIDIA: build image với `--build-arg ORT_PACKAGE='onnxruntime-gpu[cuda,cudnn]'` (xem `tools/model_server/Dockerfile`), hoặc chạy model server từ mã nguồn với `onnxruntime-gpu`.
- Trong app: Cài đặt → Model nhận diện giới tính → bật "Dùng model"; app kiểm tra GPU / VRAM của server trước khi bật, có hướng dẫn chung.

### Lưu ý
- Bản Windows và macOS **chưa ký số**: Windows SmartScreen có thể hỏi trước khi chạy ("More info" → "Run anyway"); macOS: chuột phải vào app → Open ở lần mở đầu.
- `SHA256SUMS.txt` có mã băm của mọi file; `build-info.json` ghi commit và lượt build tạo ra chúng.
- Catalog extension từ xa cần chữ ký của nhà phát triển: bản này chưa có khoá ký, nên mọi catalog từ xa bị từ chối; catalog có sẵn trong app và cài từ file zip vẫn dùng được.
- Tài liệu: `docs/operations.md` (cài đặt, model server, build), `docs/specs.md` (tính năng, CLI, RPC).
