Danh sách tag (autocomplete)

Danh sách tag là bản chụp offline, mỗi site một danh sách. Cập nhật thủ công ở đây, tự cập nhật khi mở app, hoặc theo lịch của hệ thống (kể cả khi app đóng).

Extensions

Mỗi website là một extension. Rule34 và Danbooru có sẵn; các site khác cài thêm khi cần. Extension là code Python chạy trên máy bạn: chỉ cài từ nguồn tin cậy.

Tạo extension cho site mới

Dán link một website: Lynxx đọc robots.txt và API của site, sinh manifest.json + downloader.py, chạy thử trong sandbox rồi lưu thành bản nháp. Bản nháp không tự cài: bạn xem lại rồi bấm Cài vào app, hoặc xuất file .zip.

Model nhận diện giới tính

            
Cho bộ lọc giới tính ở chế độ Tag + model: post có tag chưa đủ để biết giới tính được một model nhận diện tranh anime (WD tagger v3) xem ảnh. Model đoán tag như 1girl, 1boy, no_humans rồi dùng cùng luật với lọc theo tag; tag gợi ý trẻ vị thành niên mà model thấy được dùng để chặn thêm. Model chỉ dành cho tranh vẽ / 3D.

            
Model chạy ở model server riêng, app chỉ gọi API nên bản cài không kèm model (~380 MB). Trên máy này: python -m lynxx.model_server (lần đầu tự tải model); trên máy khác hoặc Docker cần token. Ảnh của post được gửi tới địa chỉ dưới đây để nhận diện, server không lưu ảnh. Model chạy nhanh trên GPU có VRAM; không có GPU thì chạy bằng CPU, chậm hơn và tốn RAM.

Xác minh trong Lynxx

            
Site chặn bằng bot challenge (Cloudflare): Lynxx mở site trong một cửa sổ riêng để bạn tự qua bước kiểm tra ở đó, Lynxx không tự giải hay bấm hộ. Xong thì cửa sổ tự đóng, cookie cf_clearance và User-Agent của cửa sổ được lưu vào hai ô theo site ở trên, chỉ site đó nhận. Cookie hết hạn sau vài phút tới vài giờ tuỳ site: bị chặn lại thì xác minh lại.
