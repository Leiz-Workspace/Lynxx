Thư viện

Thư viện trống. Nhập sách từ máy, hoặc cài extension ở trang Nguồn truyện rồi tải truyện về.

Nguồn truyện

Chưa có extension nào. Mở tab Đã cài hoặc Kho extension để cài extension định dạng vBook.
Extension định dạng vBook (plugin.json + src/*.js) chạy trong sandbox của Lynxx.

Tải xuống

Chưa có lượt tải nào. Mở một truyện ở trang Nguồn truyện rồi bấm Tải.
Đọc truyện
Chọn một truyện trong Thư viện, hoặc bấm Mở file… để nhập sách từ máy (EPUB, PDF, TXT, MOBI, CBZ, DOCX…).

Cài đặt

Giao diện

Theme
Icon ứng dụng
Hình nền
Ảnh nền
Độ mờ icon
Độ hiện của nền
Lớp tối phủ (dễ đọc)

Tải truyện

Thông báo khi tải xong (lúc Lynxx không ở cửa sổ trước)

Truyện tải về nằm trong thư mục dữ liệu của Lynxx và hiện ở trang Thư viện. Muốn có file EPUB, KEPUB, CBZ hoặc PDF thì mở truyện và bấm Xuất.

Kết nối

Proxy
Tạm bỏ qua proxy

Áp dụng cho extension (đọc trang, tải ảnh, tải chương) và ảnh bìa. Proxy cần mật khẩu chưa được hỗ trợ.

Nâng cao

Python cho lõi (để trống = tự dò .venv)
Launcher trên Linux (menu ứng dụng, dock)
Thư mục dữ liệu (thư viện, extension, cài đặt)
